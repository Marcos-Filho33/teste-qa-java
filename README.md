# Projeto de Testes QA em Java

##  Descrição
Projeto simples desenvolvido para praticar testes de software (QA), simulando um sistema de login.

##  Objetivo
Aplicar conceitos básicos de QA:
- Testes manuais
- Criação de casos de teste
- Identificação de bugs
- Validação de funcionalidades

##  Tecnologias
- Java

##  Testes realizados
- Login válido
- Senha incorreta
- Usuário inválido
- Campos vazios

##  Bugs encontrados
- Falta de validação de campos vazios (corrigido)
- Mensagens de erro genéricas

## Melhorias implementadas
- Validação de campos vazios adicionada
